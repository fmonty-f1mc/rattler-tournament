Use an Excel .xlsx file or a shared Google Sheets link. Each year needs its own tab named with the year and columns such as Name, Gross, HC/RC, Net, Alt. Shot, and Total. A champions summary can supply venues and award winners.

Choose years to import

Review warnings and correct course or player names before importing. Names match the participant directory regardless of case. Contact details and current directory handicaps are kept. Conflicting saved scores stop the entire selected batch without changes.

WD, DQ, starred values, and source notes remain in the saved original results. Missing scores stay blank. Live first-round standings calculate net from gross and handicap.

The score line shows the workbook's original values. In a preview, edit “Import as” to match an existing participant or correct a name. Saved originals are read-only.
