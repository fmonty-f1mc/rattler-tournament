THE RATTLER HONOURS

Awards

Keep a record of each year's champion and award winners. Use the selected tournament in the menu to record awards for past years.

Record a winner

The champion award tracks one winner per year, even if you rename it. Recording a new champion replaces the previous champion for that year. Other awards can have multiple winners.

All players in the participant directory are available, including inactive players, so you can fill in historical winners.

Manage awards

Choose New award to create one, or select an existing award to rename or delete it. Renaming updates its history; deleting keeps past winners recorded. Creating an award with a deleted name restores it.
